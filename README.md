# Articulo_data_MDPI_ES
### Datasets de entrenamiento y evaluación con ruido — CNN + AG

Se incorporaron conjuntos de datos de temperatura y humedad para el entrenamiento y evaluación de una red neuronal convolucional (CNN) optimizada mediante algoritmos genéticos (AG).

Los archivos contienen 1,000 lecturas con índices secuenciales, incluyendo datos originales y datos con perturbaciones artificiales introducidas cada 128 lecturas.

Se añadieron gráficas comparativas de temperatura y humedad que permiten visualizar el comportamiento de las señales, identificar los intervalos con ruido y analizar posibles anomalías.

**Contenido:**
- Dataset de entrenamiento con 1,000 lecturas.
- Dataset de evaluación con ruido artificial en 7 episodios.
- Gráfica comparativa de temperatura.
- Gráfica comparativa de humedad.

**Objetivo:** disponer de datos reproducibles para evaluar la capacidad de clasificación y detección de anomalías del modelo CNN + AG.
